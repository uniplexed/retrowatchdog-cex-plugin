This plugin is part of RetroWatchdog, a personal project published under the
AGPL-3.0.

## Licence of contributions

By submitting a contribution (a pull request, a patch, or code sent any other
way) you confirm that you wrote it, or have the right to submit it, and you
publish it under the project's licence, the AGPL-3.0, like everything else
here. You keep the copyright of your work.

## Legal notes

A change to what the plugin reads, how often, or from where must update
[LEGAL.md](LEGAL.md) and the manifest's `caveat`, so the person running it
is told what the source's terms say about it.

## How to contribute

Open an issue for a bug or an idea. For code: fork, branch, add or update the
tests, run the test suite, and open a pull request against `main`. Code,
comments and documentation are in English.

## Security

Do not open a public issue for a security problem. Use GitHub's "Report a
vulnerability" on this repository instead.
